# Push & Pass

Portal de conteúdo sobre automobilismo. Slogan: **Tudo sobre o mundo do automobilismo**.

O core (notícias, calendário, resultados, classificação, pilotos, equipes, circuitos e busca) é público. O login é opcional e só libera perfil, notificações e favoritos.

## Desenvolvimento

```bash
npm install
npm run dev
```

A app sobe em `http://localhost:3000`. Os dados atuais são mock (`src/content`), sem CMS nem API.

## Scripts

- `npm run dev` — servidor local
- `npm run lint` — ESLint
- `npm run build` — verificação de tipos e build
